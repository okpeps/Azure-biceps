3. Setup the resource-group automatically:


WHIZ_RG=$(az group list --query "[0].name" -o tsv)


4. Run the code:

az deployment group create --resource-group $WHIZ_RG --template-file <bicep_file>

Example:

az deployment group create --resource-group $WHIZ_RG --template-file vnet.bicep

az deployment group create --resource-group $WHIZ_RG --template-file vm1.bicep

az deployment group create --resource-group $WHIZ_RG --template-file vm2.bicep

az deployment group create --resource-group $WHIZ_RG --template-file vm2-fw-rules.bicep
